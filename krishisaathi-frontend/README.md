# Fasalya Frontend

Web application for Fasalya farm management platform.

## Stack

- React 18 + Vite
- React Router
- i18next (English + Hindi)
- Axios

## Setup

```bash
cp .env.example .env
npm install
npm run dev
```

App URL: `http://localhost:5173`

## Environment

| Variable | Default |
|----------|---------|
| `VITE_API_BASE_URL` | `http://localhost:4000/api/v1` |

## Pages (v0.1)

- Login (phone OTP)
- Dashboard
- Farms & plots
- Activity feed
- Profile
